# Attendance Calculator

A simple calculator for tracking class attendance.

Enter the number of class days held, classes per day, classes attended, planned absences, and your attendance target. The calculator estimates your current attendance, projected attendance, days needed to reach your target, and how many full days you can miss while staying at or above 75%.

## How to use

1. Enter the number of class days held.
2. Enter the number of classes in a typical day.
3. Enter the number of classes you attended.
4. Add any planned absent days and choose your target percentage.
5. Review the results.

This is a planning aid. Check your institution’s attendance rules for official requirements.
